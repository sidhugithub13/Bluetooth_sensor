# Bluetooth_sensor

The objective is to send a message through bluetooth module. HC-05 is used here due to it's simplicity and easy to use nature which is designed for transparent wireless serial communication setup.

**Hardware Requirements:**
1x Arduino Uno
1x Breadboard
1x Bluetooth Module
Jumper Wires
